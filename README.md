# Kagan Games

Русскоязычный адаптивный каталог с пятью оригинальными мини-играми Kagan Games, которые запускаются прямо в браузере.

## Запуск

Открой `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Что работает

- Навигация между главной, каталогом собственных игр и страницей разработчика.
- Поиск по каталогу, фильтр по жанру, запуск и перезапуск игр прямо на странице.
- Пять мини-игр: «Звёздный ловец», «Неоновые гонки», «Лунный прыжок», «Кристальная память» и «Защитник орбиты».
- Контакт для прямых рекламных и спонсорских предложений через WhatsApp.
- Демо-регистрация и вход по почте с профилем, сохранённым локально в текущем браузере.
- Ссылка на WhatsApp для отправки информации об игре на номер `+996 509 955 908`.

## Ограничения прототипа

Все пять игр — небольшие оригинальные браузерные мини-игры для Kagan Games; их код выполняется на странице и не загружает чужие игровые проекты. На сайте пока нет автоматических объявлений, рекламного SDK или рекламного дохода. Партнёры могут связаться для обсуждения прямого размещения; согласованный материал должен быть явно помечен как реклама, а условия и показатели охвата нельзя обещать без достоверной статистики. Сайт не собирает аналитику запусков игр, регистрацию или время входа; закрытой админ-панели в прототипе нет. Регистрация не является настоящей аутентификацией: профиль хранится в `localStorage` и доступен только в текущем браузере.

Для реальной аналитики и приватной админ-панели нужен backend с базой данных, серверной авторизацией администраторов, понятным уведомлением пользователей и правилами хранения и удаления данных. Телефон может быть контактным номером, но не заменяет сервер.

## Дальнейшая монетизация

1. Обсуждать прямые спонсорские размещения через контакт на сайте и согласовывать рекламную маркировку, формат и условия до публикации.
2. Для автоматической рекламы подготовить отдельные игровые сборки и опубликовать их на платформе, поддерживающей монетизацию игр. Подключать SDK только после регистрации и одобрения проекта на платформе, следуя её актуальной документации и правилам.
3. Не вставлять случайные рекламные скрипты в статический сайт: до проверки источника, требований к согласию пользователей и политики конфиденциальности это может навредить посетителям и проекту.
