# Kagan Games

Русскоязычный адаптивный каталог с пятью оригинальными мини-играми Kagan Games, которые запускаются прямо в браузере.

## Запуск

Открой `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Что работает

- Навигация между главной, каталогом собственных игр и страницей разработчика.
- Поиск по каталогу, фильтр по жанру, запуск и перезапуск игр прямо на странице.
- Пять мини-игр: «Звёздный ловец», «Неоновые гонки», «Лунный прыжок», «Кристальная память» и «Защитник орбиты».
- Демо-регистрация и вход по почте с профилем, сохранённым локально в текущем браузере.
- Ссылка на WhatsApp для отправки информации об игре на номер `+996 509 955 908`.
- Макет админ-панели с явно вымышленными примерами журнала активности.

## Ограничения прототипа

Все пять игр — небольшие оригинальные браузерные мини-игры для Kagan Games; их код выполняется на странице и не загружает чужие игровые проекты. Журнал в админ-макете остаётся демонстрационным. Статический прототип не собирает и не передаёт информацию о запусках игр, регистрации или входах. Регистрация не является настоящей аутентификацией: профиль хранится в `localStorage` и доступен только в текущем браузере. Макет админ-панели открыт и не защищён — не используй его для реальных пользовательских данных.

Для реальной аналитики нужен backend с базой данных, серверной авторизацией администраторов, понятным уведомлением пользователей и правилами хранения и удаления данных. Телефон может быть контактным номером, но не заменяет сервер.
